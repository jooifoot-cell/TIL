## このリポジトリについて

日々の個人開発や業務改善の中で、実際に作ったもの・理解したことを記録します。

コードを自分ですべて書くことだけを目的にせず、AIを実装支援として活用しながら、**「なぜこの仕組みが必要なのか」「システムがどう動いているのか」を理解すること**を重視しています。
