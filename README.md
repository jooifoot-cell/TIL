# TIL

Today I Learned — AI開発・自動化を中心とした学習記録です。

## このリポジトリについて

日々の個人開発や業務改善の中で、実際に作ったもの・理解したことを記録します。

現在は主に、生成AIを活用した個人開発を進めながら、GitHub / GitHub Actions / API / WordPress / Google Search Console などを使った自動化の仕組みを学んでいます。

コードを自分ですべて書くことだけを目的にせず、AIを実装支援として活用しながら、**「なぜこの仕組みが必要なのか」「システムがどう動いているのか」を理解すること**を重視しています。

## 記録方法

月ごとにMarkdownファイルを作成し、その日に行ったことと理解したことを簡潔に残します。

- [2026年9月](2026/09.md)

- Git / GitHub

## 開発スタイル

自然言語で目的や要件を整理し、ChatGPTを設計・レビュー支援、Codexを実装支援として活用しています。

完成したコードだけでなく、設計意図や失敗から学んだこともTILとして残していきます。
